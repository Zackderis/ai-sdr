# Changelog

## v2 (November 2026)

Every build brief now includes a full set of system rules.

- Exact 17-step decision order
- Default scoring model and named review buckets
- New interview question on what leads agreed to, with a consent check before enrichment
- First run always in approval mode
- Server-side send and enrichment credit caps
- Run locking, visible failures and two safe reset options
- Security rules for admin access and Slack approval links
- A test checklist Replit must pass before finishing

## v1 (November 2026)

First public release.

- Claude interview that writes a complete Replit build brief
- Native lead-database or CSV lead sources
- Eight-phase pipeline with scoring, enrichment and sequence enrollment
- Admin dashboard with approval queue and review buckets
- Apollo, Google Calendar and Slack integrations
